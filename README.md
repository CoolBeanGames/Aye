# Aye

A quiet Windows tray application for fast region screenshots and lightweight editing.

Run `dotnet run`, then right-click the eye in the notification area and choose **Take screenshot**. Drag a region to save it as a PNG under `Pictures/Screenshots` and copy it to the clipboard. Press Escape to cancel.

Press **Print Screen** while Aye is running to start the same capture flow. Aye registers itself to start at sign-in and disables Windows' competing Snipping Tool Print Screen shortcut for the current user. Choose **Edit last screenshot** from the tray menu for annotation, text, crop, scaling, and focus tools.
