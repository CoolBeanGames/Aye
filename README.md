# Aye

A quiet Windows tray application for fast region screenshots and lightweight editing.

Run `dotnet run`, then right-click the eye in the notification area and choose **Take screenshot**. Drag a region to save it as a PNG under `Pictures/Screenshots` and copy it to the clipboard. Press Escape to cancel.

On first run Aye asks whether it should become your screenshot tool. Say yes and it takes over the **Print Screen** key (disabling Windows' competing Snipping Tool shortcut for the current user) and starts at sign-in. You can flip this any time with **Default screenshot tool: on/off** in the tray menu.

Choose **Edit last screenshot** from the tray menu for annotation, text, crop, scaling, and focus tools.
